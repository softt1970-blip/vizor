# VIZOR — Автономный локальный контур разработки для Windows

**VIZOR** — системный фоновый агент, автоматизирующий перенос кода, исправлений и терминальных команд из чатов ИИ напрямую в проект без ручного копирования файлов.

---

## Возможности
1. **Глобальный захват (Alt + V):** автоперехват кода из буфера обмена.
2. **Мгновенный откат (Alt + Z):** откат изменений через Git reset.
3. **Контекстное сопоставление (Qwen2.5-Coder:7b):** умное обновление файлов по дереву проекта.
4. **Резервное копирование:** сохранение версий в .vizor_history/ перед перезаписью.
5. **Safe Runner & Feedback Loop:** выполнение команд PowerShell и автовозврат ошибок в буфер.
6. **Управление сессией:** запуск и остановка контура через start_vizor.bat и stop_vizor.bat.

---

## Использование
- **start_vizor.bat** — запуск Ollama и VIZOR в трей.
- **stop_vizor.bat** — завершение процессов и очистка VRAM.
