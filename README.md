# ⚡ VIZOR — Local AI Coding Assistant & Clipboard Bridge

> **0₽ расходов на API. Превратите любой бесплатный веб-чат (Gemini, Claude, ChatGPT) в полноценный Cursor / Copilot.**

VIZOR — лёгкий фоновый Windows-ассистент, связывающий буфер обмена с локальным кодом с помощью локальной LLM (**Ollama**). Скопируйте код из чата, нажмите хоткей — VIZOR разберёт структуру, отобразит HUD-оверлей, запишет файлы, зафиксирует Git-коммит и выполнит команду через встроенный Runner.

---

## 💡 Преимущества

* **0₽ расходов на API:** Полноценная разработка через бесплатные веб-чаты.
* **Без рутины:** Никаких переключений окон, ручного создания файлов и поиска строк.
* **100% приватность:** Разбор кода выполняет локальная модель Ollama (qwen2.5-coder).
* **Безопасность с Git Rollback:** Каждое действие изолировано коммитом, мгновенный откат по Alt + Z.

---

## ⌨️ Горячие клавиши

| Хоткей | Действие |
| :--- | :--- |
| **Alt + V** | Разобрать буфер обмена через Ollama и открыть HUD-оверлей |
| **Enter** | Подтвердить и применить изменения в проект |
| **Esc** | Закрыть оверлей без сохранения |
| **Alt + Z** | Мгновенно откатить последнее изменение через Git |
