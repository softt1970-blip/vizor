# ⚡ VIZOR — Local AI Coding Assistant & Clipboard Bridge

> **0₽ расходов на API.** Превратите любой бесплатный веб-чат (Gemini, Claude, ChatGPT) в полноценный Cursor / Copilot.

**VIZOR** — лёгкий фоновый Windows-ассистент, связывающий буфер обмена с вашей локальной кодовой базой. Скопируйте код или команду из чата, нажмите хоткей — VIZOR распознает пути, отобразит визуальный Diff в HUD-оверлее, применит файлы, выполнит тесты через Runner и автоматически соберёт ошибку в буфер при сбое.

---

## 💡 Преимущества

* **0₽ расходов на API:** Полноценный цикл разработки через бесплатные веб-чаты и локальные модели.
* **Без рутины:** Никаких переключений окон, ручного создания файлов, поиска нужных строк и вставки.
* **Визуальный контроль (Diff):** Мгновенный предпросмотр изменений (`+` / `-`) до внесения правок на диск.
* **Безопасность и откат:** Автоматический бэкап перед каждой правкой и мгновенный Rollback по `Alt + Z`.
* **Автоперехват сбоев:** При падении команды VIZOR упаковывает контекст файла и `stderr` в готовый промпт для нейросети.
* **Голосовая обратная связь:** Озвучивание статусов применения и ошибок через системный Windows SAPI5.

---

## ⌨️ Горячие клавиши

| Хоткей | Действие |
| :--- | :--- |
| **`Alt + V`** | Открыть HUD-оверлей (просмотр кода / Diff) и применить изменения (`Enter`) |
| **`Enter`** | Подтвердить и применить изменения в проект + запустить Runner |
| **`Esc`** | Закрыть оверлей без сохранения |
| **`Alt + Z`** | Мгновенно отменить последний наложенный патч (Rollback) |
| **`Alt + C`** | Собрать контекст проекта или файла в буфер для вопроса в чат |

---

## ⚡ Быстрый старт

1. Запустите фоновый процесс VIZOR:
   ```powershell
   & "H:\VIZOR\.venv\Scripts\python.exe" "H:\VIZOR\src\clip_watcher.py"
```
2. Скопируйте блок с кодом из чата и нажмите **`Alt + V`**.
